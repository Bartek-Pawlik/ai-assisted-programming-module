# Project grading rubric

The project is **60% of the module**. Back to **[the brief](brief.md)**.

Your project is graded across three equally weighted areas (approximately
33% each):

| Area | Poor<br>(0-39) | Fair<br>(40-49) | Good<br>(50-59) | Very Good<br>(60-69) | Excellent<br>(70-100) |
|------|----------------|-----------------|-----------------|---------------------|---------------------|
| **AI Usage<br>(~33%)** | • No AI-USAGE.md<br>• No advanced technique<br>• Basic autocomplete only<br>• No prompt examples<br>• No documentation | • Minimal AI-USAGE.md<br>• Attempted MCP/RAG but incomplete<br>• Few prompt examples<br>• Little reflection<br>• Basic documentation | • Complete AI-USAGE.md<br>• Working MCP or RAG<br>• Good prompt examples<br>• Shows learning<br>• Adequate documentation | • Detailed AI-USAGE.md<br>• Well-implemented MCP or RAG<br>• Excellent prompts<br>• Clear methodology<br>• Thoughtful reflection | • Comprehensive AI-USAGE.md<br>• Both MCP and RAG, or advanced implementation<br>• Sophisticated prompting<br>• Innovation shown<br>• Exceptional documentation<br>• Clear impact analysis |
| **Technical Implementation<br>(~33%)** | • Inconsistent code<br>• Unfinished sections<br>• Poor formatting<br>• No comments<br>• Doesn't compile | • Basic competence<br>• Minimal comments<br>• No new elements<br>• Meets minimums<br>• Some bugs present | • Good functionality<br>• Well-commented<br>• Some new features<br>• Clean code<br>• Mostly bug-free | • Strong implementation<br>• Comprehensive comments<br>• Multiple new features<br>• Professional code<br>• Robust error handling | • Outstanding implementation<br>• Exceptional code quality<br>• Innovative features<br>• Production-ready<br>• Advanced techniques<br>• Best practices throughout |

### Grading Notes:
- Each area contributes approximately one-third to your final grade
- To achieve higher grades, you must perform well across ALL three areas
- Missing critical components (AI-USAGE.md, screencast, advanced technique) will cap your grade at 40%
- The grading is holistic - exceptional work in one area can partially compensate for weaker performance in another, but all areas must meet minimum standards.
