## 🎯 Learning Path

### Part 1: GitHub Copilot Ask Mode (20 minutes)
Students learn to use Copilot for:
- Code explanation
- Learning new concepts
- Debugging assistance

**Key Files:**
- `mystery_code.py` - Composite pattern with factory
- `buggy_code.py` - Grade management system with bugs

---

### Part 2: GitHub Copilot Edit Mode (25 minutes)
Students learn to use Copilot for:
- Code generation
- Refactoring
- Bug fixing

**Key Files:**
- `validators.py` - Generate EmailValidator class
- `messy_code.py` - Refactor poor code
- `broken_calculator.py` - Fix calculator bugs

---

### Part 3: GitHub Copilot Agent Mode (25 minutes)
Students learn to use Copilot for:
- Multi-file feature implementation
- Autonomous bug investigation
- Test generation

**Tasks:**
- Build complete task management system
- Investigate and fix persistence bugs

---

### Part 4: Cloud Coding Agent (30 minutes)
Students learn to:
- Trigger cloud agents with specific hashtag
- Review AI-generated pull requests
- Iterate with feedback

**Tasks:**
- Implement authentication system asynchronously
- Review and improve generated PR

---

### Part 5: Google Jules (20 minutes)
Students learn to:
- Create well-defined issues
- Assign work to Jules
- Compare different AI agents

**Tasks:**
- Create CSV export feature issue
- Compare Jules vs Copilot Cloud
- Critical evaluation
